# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop built with React and Redux Toolkit.

## Features

- Landing page with the company name, an About Us section and a **Get Started** button
- Product listing page with houseplants grouped into categories, each with a thumbnail, name, description and price
- **Add to Cart** buttons that add the plant to the cart and become disabled once the plant is added
- Navbar with links to Home, Plants and Cart, and a cart icon that shows the total number of items
- Shopping cart page that shows each plant's thumbnail, name, unit price and total cost, with buttons to increase, decrease or delete items
- Total cart amount, a **Checkout** button ("Coming Soon") and a **Continue Shopping** button

## Tech stack

- React (Vite)
- Redux Toolkit and React Redux

## Run locally

    npm install
    npm run dev
